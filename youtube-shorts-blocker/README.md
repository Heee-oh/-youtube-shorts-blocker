# YouTube Shorts Blocker

크롬에서 유튜브 쇼츠만 차단하는 확장 프로그램입니다.

## 기능

- 쇼츠 주소 접속 및 유튜브 내부의 쇼츠 이동 차단
- 쇼츠 추천 카드와 메뉴 숨김
- 일반 영상·검색·구독은 그대로 이용
- 개인정보 수집 및 외부 전송 없음

## 설치

1. 이 저장소를 다운로드하고 압축을 풉니다.
2. 크롬에서 `chrome://extensions`에 접속합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
5. 열려 있는 유튜브 탭을 새로고침합니다.

설치한 폴더는 이동하거나 삭제하지 마세요. 별도 설정 없이 작동합니다.

## 참고

- 시크릿 모드는 확장의 **세부정보 → 시크릿 모드에서 허용**을 켜야 합니다.
- 쇼츠 영상을 일반 영상 주소(`/watch?v=…`)나 임베드로 열면 재생될 수 있습니다.
- 유튜브 화면 구조가 바뀌면 일부 카드가 다시 보일 수 있습니다.
- 제거하려면 `chrome://extensions`에서 확장을 삭제합니다.
